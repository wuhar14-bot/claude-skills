# claude-skills

A collection of skills for [Claude Code](https://claude.ai/code) — installable prompts that give Claude new behaviors.

## Available Skills

| Skill | What it does |
|:------|:-------------|
| [boil-down](./boil-down/) | Wraps up a session into structured notes, a hand-off brief, and syncs your task backlog |

## How to install a skill

1. Find the skill folder you want (e.g., `boil-down/`)
2. Copy the `SKILL.md` file into your Claude Code skills folder:
   - **Mac/Linux:** `~/.claude/skills/<skill-name>/SKILL.md`
   - **Windows:** `C:\Users\<you>\.claude\skills\<skill-name>\SKILL.md`
3. Follow any configuration steps in the skill's own `README.md`
